# KLVN DJ Press Kit

## GitHub Pages structure

Upload the contents of this folder to your GitHub repository:

- index.html
- style.css
- images/
- downloads/

The website uses relative paths, so it works with GitHub Pages.

## Photos

Put your photos in `images/` using the filenames listed in `images/README.txt`.

## Downloads

Put your EPK, bio, photos ZIP, and technical rider inside `downloads/`.

## GitHub Pages

Repository → Settings → Pages → Deploy from branch → main → / (root) → Save.
